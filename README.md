# Back Office GMIH Ebenhaezer Ternate

Repository untuk Back Office GMIH Ebenhaezer Ternate.

Fitur:
- Dashboard
- Profil Gereja
- Kelola Layout
- Banner & QRIS
- Jadwal Ibadah
- Ministri
- Dokumentasi Foto
- Arsip Foto Jemaat
- Kontak & Header
- Pengaturan

Aplikasi menggunakan GitHub Pages untuk antarmuka dan Supabase untuk autentikasi serta data Back Office.
